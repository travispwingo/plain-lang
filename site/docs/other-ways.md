## Other ways you can write things

Plain understands these too. Each one means exactly the same as the main wording. `plain tidy` changes them to the main wording for you.

- `SHOW "Hi"` is read as `show "Hi"`. Capitals don't matter.
- `Then show "Done"` is read as `show "Done"`. Words like please, now, then and next at the start of a line are left out.
- `show the total` is read as `show total`. You can leave out a, an and the.
- `isn't` is read as `is not`.
- `bill * rate` is read as `bill times rate`.
- `display`, `load`, `fetch`, `else` and `return` are read as `show`, `read`, `read`, `otherwise` and `give back`.
- `if answer is "y" or "yes"` is read as `if answer is "y" or answer is "yes"`.
- `if age is more than 12 and less than 20` is read as `if age is more than 12 and age is less than 20`.
- `for each sale in sales` is read as `repeat for each sale in sales`.
- `$42.50` is the number 42.50, and `15%` is 0.15.
- `“curly quotes”` from Word or Google Docs work like `"straight quotes"`.
